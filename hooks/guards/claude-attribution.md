name: warn-claude-attribution
enabled: true
event: bash
pattern: (?s)(?=.*\b(?:gh\s+pr\s+(?:create|edit|comment)|git\s+commit)\b)(?=.*(?:Generated with \[?Claude(?: Code)?|Generated by \[?Claude(?: Code)?|Created by \[?Claude(?: Code)?|Authored(?: by| with) \[?Claude(?: Code)?|Co-Authored-By:\s*\[?Claude))
action: warn
case_sensitive: false
env_var: DX_ATTRIBUTION_CLAUDE_FORBIDDEN
---

Claude attribution in a PR or commit command.

This project's attribution mode (`attribution:` under `## Attribution` in
`.dex/dex.md`, `dex` when unset) leaves Claude attribution out. In `dex` mode,
use `Generated by Dex` in PR bodies when attribution is needed and
`Co-Authored-By: Dex <noreply@dexcode.ai>` for commit trailers; in `none`
mode, add no AI attribution. Run `dx attribution mode` to check. The warning
applies only inside a Dex session, and not in the `claude` or `both` modes.

If a commit with the wrong trailer is already pushed, leave it and use the
right trailer from the next commit on. Do not amend or force-push to fix it.
