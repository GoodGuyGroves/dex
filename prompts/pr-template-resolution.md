# PR Template Resolution

Phase 5 writes the PR description (`$DEX_DIR/prompts/workflows/dxpr.md`) and
audits it (`$DEX_DIR/prompts/phase-audits/5-pr.md`). Both use this file to decide
which template is active, so they always agree.

## Which template is active

Use the first source that applies:

1. **Declared in `.dex/dex.md`.** Check with the shared helper:

   ```bash
   source "${DEX_DIR:-$HOME/work/dex}/lib/common.sh" || exit 1
   PR_TEMPLATE_RC=0
   PR_TEMPLATE=$(dx_project_pr_template "$(pwd)") || PR_TEMPLATE_RC=$?
   ```

   - `0`: `$PR_TEMPLATE` is the template's path.
   - `1`: the project declared none. Go to source 2.
   - `2`: the declaration is unusable (malformed block, absolute path, a path
     outside the repository, or a missing or empty file). Report the reason
     in the Phase 5 summary, then go to source 2. Do not stop Phase 5 for it.
2. **Referenced in project instructions.** `AGENTS.md`, `CLAUDE.md` or
   `.dex/dex.md` names a PR description template or prompt.
3. **Dex's default:** `$DEX_DIR/prompts/pr-description.md`.

`.github/pull_request_template.md`, `.github/PULL_REQUEST_TEMPLATE.md` and
`.github/PULL_REQUEST_TEMPLATE/` are never the active template on their own.
Dex may have installed that file itself, and `gh pr create --body-file` does
not read it. Use one only when source 1 or 2 points to it.

State the outcome in the Phase 5 summary as one line:
`PR template: default` or `PR template: <repo-relative path>`.

## Writing to a project template

- Fill in exactly the sections the project template defines, in its order.
  Keep its headings, checkboxes and footer.
- Do not add sections that only Dex's default template has: Testing
  Performed, Key Technical Decisions, Business Impact, Performance, Deployment
  Notes, Breaking Changes, Files Changed or metrics. The project left them out
  on purpose.
- Lifecycle content still goes in, under the template's closest section or,
  when none fits, at the end of the body: the ticket link, sub-issue status,
  Coherence Contract deviations, the debt ledger, and Visual Evidence when the
  UI proof is `READY`.

## Rules for every template

- Run the `dex:humanizer` (`humanizer` outside Claude Code) skill on the title
  and body, preserving the template's structure.
- Attribution is Dex-only. Never include `Generated with Claude Code`,
  `Generated by Claude`, or Claude co-author trailers.
- End with `Generated by Dex` unless the active template forbids
  generated-by footers.
